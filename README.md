# CS 370: Pirate Intelligent Agent

## Project Overview

This project involved developing a pirate intelligent agent capable of navigating a maze and finding treasure using reinforcement learning. The project applied concepts from artificial intelligence, neural networks, Q-learning, and reward-based decision-making.

## What Work Was Completed?

The starter code provided the maze environment, the `TreasureMaze` and `GameExperience` classes, the neural network structure, and supporting functions for the intelligent agent. My work involved implementing and refining the `qtrain()` function, which trains the agent through exploration and exploitation, records experiences, updates Q-value estimates, and uses a target network to support learning. I also worked on action selection and evaluation to test the agent's ability to reach the treasure.

## What Do Computer Scientists Do, and Why Does It Matter?

Computer scientists design, develop, test, and improve computational systems to solve problems efficiently and reliably. Their work matters because software and intelligent systems influence fields such as healthcare, education, business, security, and transportation. Developing these systems requires technical knowledge as well as an understanding of the people who will use them and the consequences of their implementation.

## How Do I Approach a Problem as a Computer Scientist?

I approach problems by identifying the requirements, breaking complex tasks into smaller components, selecting appropriate computational methods, and testing the results. In this project, reinforcement learning provided a way to teach an agent to make decisions through environmental feedback rather than programming a complete solution route. Debugging the implementation also demonstrated the importance of checking input dimensions, legal actions, reward handling, and evaluation results systematically.

## What Are My Ethical Responsibilities to the End User and the Organization?

My ethical responsibilities include developing reliable software, protecting user data, communicating limitations honestly, and considering the consequences of automated decisions. Intelligent systems should be tested carefully because an agent that appears to work in one situation may fail in another. Developers should report results accurately, avoid overstating a system's capabilities, and ensure that its use aligns with the organisation's requirements and the interests of its users.
